Как это будет работать
Архитектура dashboard уже поддерживает загрузку данных 2026 года. После их появления система автоматически сопоставит по каждому игроку из списка 2025:
  • изменение рыночной стоимости (€);
  • изменение статистической эффективности;
  • факт перехода в другой клуб;
  • изменение UI между сезонами.
Результат валидации не генерируется. Пока данные сезона 2026 отсутствуют, dashboard показывает статус «Validation in progress» и не выводит никаких выводов о подтверждении модели.

How KVI works

PLAYER DATA→ POSITIONAL Z-SCORE→ WEIGHTS→ KVI→ AAF→ UI
z = (x − μ) / σ
KVI = Σ(wi × zi)
KVI_adj = KVI × AAF
UI = norm(KVI_adj) − norm(Market Value)
Позиционная нормализация
Z-оценка считается внутри позиционной группы (FW / MF / DF), а не среди всех игроков. Форвард сравнивается с форвардами, защитник — с защитниками. Вратари исключены из модели.
Age Adjustment Factor
age < 25: AAF = 1 + 0.05 × (25 − age) / 10
25 ≤ age ≤ 29: AAF = 1
age > 29: AAF = 1 − 0.03 × (age − 29) / 10
